# Built-in static assets

This directory is publication output for **approved** static assets only.

Source candidates live under `assets/sources/`. Sanitized review candidates and thumbnails are generated by `tools/asset-pipeline/`. A candidate must pass manifest/taxonomy/SVG/license/provenance validation and, for generated/original artwork, carry explicit review evidence before tooling may publish it here.

The current representative seed intentionally remains `draft` pending Main visual review, so no seed artwork is auto-published as a product built-in merely because the pipeline can process it.
