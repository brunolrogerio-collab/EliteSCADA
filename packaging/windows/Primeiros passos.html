SCADIVO para Windows

Versão Alpha para avaliação em Windows 11 x64. A instalação requer uma conta de administrador.

Primeiro acesso

  1. Abra SCADIVO pelo menu Iniciar. O navegador abre a interface local.
  2. Crie o primeiro administrador e guarde a senha. Depois entre na Engenharia para criar ou importar um projeto compatível.
  3. Abra Licenciamento para ver o uso e aplicar a licença emitida para esta máquina.

Monitor e diagnóstico

O ícone SCADIVO na bandeja mostra se o serviço responde. O menu abre Licenciamento e permite iniciar, parar ou reiniciar o serviço com autorização do Windows.

As portas padrão são Web 18080, API 15120 e PostgreSQL 15432. Na primeira instalação, o assistente permite escolher outras portas. Os serviços escutam somente no próprio computador.

Se a instalação falhar, confira %ProgramData%\SCADIVO Windows\logs.

Desinstalar

Em Aplicativos Instalados do Windows, escolha SCADIVO e selecione Desinstalar.

  • Desinstalar e manter os dados deixa o banco, os usuários, a configuração e a licença em %ProgramData%\SCADIVO Windows.
  • Desinstalar e apagar os dados locais apaga essa pasta após confirmação. Guarde um backup se quiser recuperar os dados mais tarde. A próxima instalação inicia um banco novo.
