# SCADIVO — English manual

Choose what you need to do; you do not need to read every chapter in sequence. If you are starting, follow this route:

1. Open [First project](30-FIRST-PROJECT.md) and display a known reading without physical equipment.
2. Use [Data Sources and TAGs](03-ENGINEERING-DATA-SOURCES-TAGS.md) to prepare the value's origin.
3. Build the drawing in [Screens, Popups and objects](05-SCREENS-AND-OBJECTS.md). Add Scripts when custom logic is needed.
4. Save, publish and activate through project lifecycle; check the revision and reading in [Runtime](27-SESSIONS-AND-DIAGNOSTICS.md).

For an unfamiliar term, consult the [Fundamentals glossary](01-ELITESCADA-FUNDAMENTALS.md). To find a field or command, use installed Help search. Detailed guides explain choices after the first example.
