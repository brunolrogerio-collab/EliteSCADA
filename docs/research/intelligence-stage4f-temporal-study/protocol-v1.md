## 1. Question and evidence boundary

Compare the instantaneous covariance-aware squared residual distance against an EWMA of that same score for sustained deviations in the declared synthetic motor/pump generator. The sole temporal coefficient is alpha 0.20. Shrinkage is fixed at 0.05. The hypothesis is that temporal accumulation may improve the sustained-deviation / false-episode tradeoff; the experiment does not presume improvement.

All rows, timestamps, context, quality, synchronization flags, labels and elapsed exposure are synthetic. This transparent generator is not measured equipment, a digital twin, plant data, field validation, equipment health, diagnosis, RUL, standards evidence, or an EliteSCADA product implementation. No product score, threshold, API, database, UI, Preview, HA, driver, license or service is read or changed. No external archive, owner data, network service, GPU, or external numerical package is used. Per-sample traces and scores remain ephemeral.

## 2. Finite comparison

For each eligible observation, fit the contextual expected value and robust residual scale using fit-partition nonfault runs only. Standardize and center residuals by the fit-only robust center/scale and transformed fit mean. The joint statistic is the squared Mahalanobis distance using the fit residual covariance with fixed `lambda=0.05` shrinkage toward the identity. The marginal control is `max(abs(z_j))` on the identical standardized residual vector; it is not a joint score.

The four joint candidates are exactly:

| Statistic | Quantile |
| --- | ---: |
| Instantaneous joint distance | 0.99 |
| Instantaneous joint distance | 0.999 |
| EWMA of joint distance, alpha 0.20 | 0.99 |
| EWMA of joint distance, alpha 0.20 | 0.999 |

The four marginal controls use the same instantaneous/EWMA forms and quantiles. Controls are always reported, never eligible to win selection. A threshold for each of the eight candidates is the empirical nearest-rank quantile of that candidate's calibration nonfault score list: sorted position `ceil(q*n)-1` (zero-based). No other statistic, shrinkage, alpha, quantile, feature, context, threshold or optimizer is permitted.

EWMA is `S_t = 0.20*Y_t + 0.80*S_(t-1)`, where `Y_t` is the current candidate's instantaneous statistic. At the beginning of each independent run, `S_-1` is the fitting-only arithmetic mean of that same instantaneous statistic over fit nonfault rows. The first eligible sample updates from this initialization; no warm-up sample is removed. The fit mean is frozen before calibration. For an ineligible expected cohort, a gap, context/profile/version mismatch, or run boundary, EWMA and episode state reset; no value is imputed, interpolated, or carried across unknown availability. If the current row begins after an explicit reset and is eligible, it is the first updated sample from the same fit-only initialization.

## 5. Fit-only model, calibration, selection and freeze

On each OS, fit ordinary least squares with fixed design `[1, load_fraction, (speed_rpm-1450)/20]` and an intercept for each target from the 60 fit nonfault runs. Compute residual median and `1.4826*MAD` per target from those same fit residuals; zero/nonfinite scales fail closed. Standardize fit residuals, calculate their sample covariance and fit mean, and report covariance rank/condition. Apply only fixed shrinkage 0.05 for the joint factor; reject nonfinite, non-positive-definite, or condition `>1e6`. No calibration/holdout values influence OLS, centering, scale, covariance, fit EWMA initial means, or shrinkage.

Calibration uses IDs 60–119, all seven scenarios with paired variants. Candidate thresholds are the predeclared calibration-nonfault quantiles above. The four joint candidates are calibration-feasible only if all unchanged point-estimate targets hold: point FP `<=1%`, false episodes `<=1 per 24 eligible simulated hours`, recall `>=90%` for each required strong class, and fraction of all strong groups confirmed within 600 simulated seconds `>=90%` for each class; conditioning must be acceptable. No candidate choice is inferred from marginal controls. Among feasible joint candidates choose, in order: highest minimum timely-detection fraction across the strong classes; highest minimum recall; fewer nonfault false episodes; instantaneous before EWMA; then lower quantile. If none is feasible, freeze instantaneous joint/q0.99 as an explicitly calibration-infeasible reference. This fallback is not permission to claim success. The selected configuration, all thresholds, fit reference values, calibration-only aggregates, protocol/manifest/code/test/helper hashes, and exact pre-holdout source commit are committed before any holdout generation.

## 6. Eligibility, temporal boundaries and episodes

Each score requires three finite targets and finite declared context; `running=true`; verified, unique, cadence-aligned synthetic time; `quality=Good`; matching `pump-profile-v1` context and `model-v1` version; and known cadence. A duplicate time invalidates all rows sharing the duplicate key. Missing/bad/nonfinite/misaligned/unsynchronized input, missing expected sample, context/version change, or gap resets EWMA and episode state as unknown, never as a normal vote. A `break_before` eligible row starts a new state window. Run boundaries always reset both methods.

Use the accepted complete rolling five-eligible-decision / 3-of-5 confirmation and five-consecutive-below termination/rearm convention. A point is above only when score `>` threshold. Confirmation is timestamped at the current (fifth-decision-window) index. The five-below count includes below-threshold values already trailing in the confirming window. Termination resets active state but preserves still-consecutive eligible decision history; only gap, context/version, ineligibility, or run reset clears that history. No artificial sleep is used for simulated time. Event latency is confirmation index minus onset index times 10 seconds; a pre-onset episode is not retroactively credited as post-onset event detection. Misses remain in the strong-class denominator.
