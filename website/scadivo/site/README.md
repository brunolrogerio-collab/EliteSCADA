# Scadivo — site preview

Static, bilingual marketing site. No build step is required; runtime PNG assets are stored in `assets/`.

## Preview

Open `index.html` in a modern browser or serve this folder as static files. Portuguese is the default; the EN button switches to English and remembers the choice in local storage.

## Before public launch

- All demo buttons use the short URL `https://scadivo.com/demo`. The page embeds the public unified Runtime at `https://scadivo-demo.jywwfm.easypanel.host/`, keeping the SCADIVO domain visible in the address bar. EEE is the initial screen; select RHOs in the Runtime navigation to view that process.
- The EEE and RHOs cards use screenshots captured from the current Runtime. Both demos are simulations, without PLC communication or live telemetry.
- Add an approved business contact and privacy/legal information.
- Connect checkout only after payment provider, licensing tiers, issuance/signing service, fulfillment, refunds and tax handling are configured and tested. The current licensing section deliberately says this is in preparation and does not collect payment or issue licenses.
- Confirm final brand direction and product-name migration with the application integration owner. The site identifies SCADIVO as the current brand.
